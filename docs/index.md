
# LP-Tracker

**Track League of Legends LP progression, events and player performance in one place.**

Welcome to the official LP-Tracker documentation.

LP-Tracker is a self-hosted platform for tracking League of Legends players and managing competitive LP events.

## Features

- Live leaderboards and player statistics
- Scheduled and active events
- Historical matches and LP progression
- OBS-compatible stream overlays
- Riot Games API and OP.GG integration
- Administration and monitoring
