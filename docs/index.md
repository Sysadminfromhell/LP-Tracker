# LP-Tracker Documentation

**Track League of Legends LP progression, events and player performance in one place.**

LP-Tracker is a self-hosted platform for League of Legends player tracking and competitive LP events. This wiki is organized by task and audience.

## Scope and feature status

The current implementation includes LP-based events, player and event history, recorded matches, streaming overlays, diagnostics and live updates.

Roadmap features are **not** necessarily present in the current release. In particular, configurable League-style scoring and team functionality are planned rather than documented here as shipped behavior.
