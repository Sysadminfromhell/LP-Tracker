# Roadmap

The authoritative milestone list is the repository's [ROADMAP.md](https://github.com/Sysadminfromhell/LP-Tracker/blob/main/ROADMAP.md).

Current main-line capabilities include LP-based events, historical event/player views, live updates, streaming overlays, administrator workflows and diagnostics.

Planned roadmap areas include configurable scoring, improved player analytics, live event feeds, richer overlays, event templates, comparisons and future extensibility/team support.

**A roadmap milestone is not proof that a feature has shipped.** Check its release status before adding it to the user guide.

Documentation changes should accompany relevant code changes so that behavior and operating instructions stay aligned.
