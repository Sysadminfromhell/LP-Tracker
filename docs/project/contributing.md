# Contributing & Security

LP-Tracker is developed in the public [GitHub repository](https://github.com/Sysadminfromhell/LP-Tracker).

Read [CONTRIBUTING.md](https://github.com/Sysadminfromhell/LP-Tracker/blob/main/CONTRIBUTING.md) before submitting a pull request. It explains the repository layout, tests and project conventions.

## Documentation changes

Wiki source lives in `docs/`. Configuration is in `zensical.toml`. Preview with `zensical serve` and validate with `zensical build --strict`.

Changes to API behavior, event rules, environment variables and public features should include corresponding documentation.

## Vulnerability reporting

Follow [SECURITY.md](https://github.com/Sysadminfromhell/LP-Tracker/blob/main/SECURITY.md). Do not publish sensitive exploit details as a public issue.
